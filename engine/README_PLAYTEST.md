# Play-test the native engine on Windows

## Easiest method
Open the repository's Actions tab, open the latest **Windows Engine Build**, and download the **HellzYeahRetroEngine-Windows** artifact after the workflow succeeds.

## Local build
Double-click `engine/build-windows.bat` on a PC with Visual Studio 2022 Desktop development with C++ installed.

## Current play controls
A/D or arrows move.
Space/Z jumps.
Q/E switches Mario, Luigi and Bowser.
X/J attacks.
C/K uses the special attack.
R restarts the stage.
F5 toggles editor/play-test.

The project does not include ripped Nintendo graphics, ROM data, music, or sound effects.
