# Gameplay roster target

The engine roster is data-driven so characters/enemies can have unique behavior without being hard-coded into a ROM sprite table.

## Heroes implemented in data
Mario, Luigi, Bowser.

## Mushroom-world enemy archetypes implemented
Goomba, Koopa Troopa, Koopa Paratroopa, Bob-omb, Buzzy Beetle, Shy Guy, Hammer Bro, Lakitu.

## Kong-world enemy archetypes implemented
Kritter, Klump, Necky, Zinger, Gnawty, Klaptrap, Army, Mini-Necky, plus a Kong Guardian boss.

More character/enemy definitions can be added to GameData.hpp as their unique AI/abilities are implemented. Names identify the intended fan-game roles; proprietary Nintendo graphics/audio are not bundled.
